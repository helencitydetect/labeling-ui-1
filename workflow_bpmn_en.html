Estimated impact
One measured input (blocked/bad-angle marking) + modeled ranges for the rest
Per 1,000 images/day unless noted. The 90/10 splits at blocks 2 & 5 are from this design. Per-action durations and AI-confidence shares are assumptions — shown as optimistic vs. conservative ranges — except the blocked/bad-angle row, which uses the actual figures given (3,000 images/day, 5–6s each, 3 annotators).
Blocked / bad-angle marking — team time / month: ~92–110 h (real: 3,000/day × 5–6s × 3 annotators) → ~9–11 h (only ~10% still escalated to a human) — ≈ 90% less — this task moves almost entirely from human to AI (blocks 0 + 2)
Same, per annotator / month: ~31–37 h → ~3–4 h — ≈ 4 fewer working days / month per annotator on this one task alone
Annotator time, 1,000 images/day — optimistic: ~11.1 h (~1.6 annotators) → ~1.3 h (~0.2 annotators) — ≈ 85–90%; assumes 90% AI confidence, 40s/annotation (per block 2/5 splits)
Annotator time, 1,000 images/day — conservative: ~16.7 h (~2.4 annotators) → ~6.7 h (~1 annotator) — ≈ 55–65%; assumes only 60% AI confidence, 60s/annotation
Manual reviews per persistent lot / year: ~52 (weekly) → ~13–17 conservative · 6–13 optimistic — ≈ 70–80% fewer reviews for abandoned / vacant lots
AI second-pass check overhead (block 8): — → +5–10% time on flagged images only — Small added cost, recovers missed attributes
  • The blocked/bad-angle row is the only one built from figures you gave directly — everything else is modeled and shown as a range.
  • Optimistic vs. conservative differ only in two assumptions: AI confidence share (90% vs 60%) and seconds per full annotation (40s vs 60s).
  • The real-world number likely starts closer to conservative and moves toward optimistic as confidence thresholds get tuned on production data.
  • Replace remaining assumptions once frequency data / a time-motion pilot is available.
